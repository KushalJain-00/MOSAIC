# MOSAIC Financial and Engineering Glossary

| Term | Definition |
|---|---|
| Underlying | Economic reference asset or index for a derivative |
| Instrument | Specific security/index/contract identity within MOSAIC |
| Venue | Exchange or execution location, distinct from data provider |
| Option right | Call or put entitlement; not a prediction of market direction |
| Expiry | Contract termination/exercise/settlement reference date per contract rules |
| Lot size | Applicable quantity/units per contract specification; can change |
| Open interest | Outstanding contract positions according to source definition and release timing |
| Bhavcopy | Exchange report containing period-level market observations and related fields as defined by format |
| UDiFF | Unified Distilled File Formats for harmonized market participant/clearing files |
| L2 | Market-by-price depth; price levels aggregated, not full individual order lifecycle |
| L3 | Individual order-level events where a venue actually supplies them |
| Canonical data | Normalized observations with defined semantics; not a universal truth claim |
| Curated data | Derived/resampled/adjusted dataset with explicit transformation provenance |
| Availability time | When an input was knowable to a strategy, distinct from effective date |
| Manifest | Published list of immutable artifacts and their meaning/version |
| Idempotency | Repeating a defined operation does not create duplicate logical effects |
| Atomic rename | Filesystem publication operation when supported on same filesystem; not a DB transaction |
| Point-in-time | Historical reconstruction based on information available at past decision timestamp |
| Walk-forward | Time-ordered repeated model fit/test evaluation procedure |
| Adverse selection | Tendency to trade when counterparty information makes fills unfavorable |
| Implementation shortfall | Difference between execution outcomes and a defined decision benchmark, costs included |
| OMS | Order-management system owning internal order lifecycle |
