# Mixed mastery assessment — one prompt at a time

**Tutor instructions:** at the final exam, choose at least one independent question per subskill plus one integrative problem. Do not reveal the next question while assessing the current one. Use a novel scenario, not a verbatim worked example. A passing final assessment requires target levels across all subskills.

1. **Expectation:** derive breakeven hit probability for a synthetic asymmetric payoff after fees; defend what changes if execution is conditional on signal quality.
2. **Bayes:** reconstruct posterior probability given base rate, sensitivity and false-positive rate; expose base-rate neglect.
3. **Statistics:** explain why a 2.5 sample Sharpe selected among 200 parameter runs is not a sufficient inference.
4. **Instrument identity:** distinguish two same-strike NIFTY options with different expiries; design effective-dated lot sizes.
5. **Derivatives:** compute call net P&L including premium, lot multiplier and fees; discuss short option exposure.
6. **Time series:** compute a 2-period compound return and identify leakage in a near-close signal.
7. **Data governance:** draw raw→canonical→curated lineage and when two corrected source versions must remain accessible.
8. **Recovery:** reason through filesystem published / SQLite not committed, with manifest-gated visibility.
9. **Queries:** propose and benchmark a Parquet layout for EOD equity and F&O instruments.
10. **Backtesting:** create a protocol with held-out periods, realistic fills and a negative control.
11. **Risk:** separate strategy target, allocator, risk authority and actual broker position.
12. **Concurrency:** choose sequential/async/thread/process for two workloads given 8GB laptop constraints.

**Integrative case:** a new provider claims free historic options candles, dates are incomplete, underlying symbols have changed, and a corrected report arrives after model training. Produce source qualification, temporal identity, ingestion, dataset release, query and experiment invalidation decisions. The answer must state unverified licensing explicitly.
