# Evaluation center

The learning system uses the uploaded Socratic Tutor protocol: one question at a time during live tutoring, diagnostic before teaching, evidence-based 0–5 levels and independent delayed checks.

- `mixed-assessment.md`: question bank for a final cross-track oral/written exam.
- `capstone-data-platform.md`: build an auditable V1 data pipeline with test evidence.
- `scoring-rubric.md`: what qualifies as 0–5, evidence requirements and failure conditions.

**Answer discipline:** learner-facing files deliberately do not supply a complete solution key. Explanations or solutions should be offered after attempts and probing, then re-tested in a novel variant. Do not mark progress from reading.
