# Mastery scoring rubric

| Level | Meaning | Evidence |
|---|---|---|
| 0 | Unaware | no reliable understanding demonstrated |
| 1 | Heard of it | can recognize vocabulary only |
| 2 | Follow along | reproduces explained steps, cannot yet transfer |
| 3 | With help | can solve a related task using hints |
| 4 | Independently | passes **two independent checks**, one delayed without hints |
| 5 | Can teach + edge cases | solves adversarial case and accurately explains mechanism |

## Evaluation rules

- Diagnostic scores require actual answers, not inferred scores from profile/background.
- Wrong response triggers a narrower question, not immediate solution dumping.
- If 2–3 prompts fail, give a brief correction, then test differently.
- Retest past topics unexpectedly; reduce level if delayed recall fails.
- A copied implementation is not proof of independent understanding.
- Final mixed exam must cover every active subskill and integrate at least two domains.

## Practical code review

For any technical claim, ask: what invariant is asserted? What fixture or test proves it? Could a different source, timestamp or market lifecycle rule break it? If the candidate cannot explain these, do not mark 4/5.
